Request: no user may create a company — only a manager adds them. Companyless user

Caps: User 1, Manager 3, Admin unlimited.

### Server

  `{USER:1, MANAGER:3, ADMIN:null}`, `tierFor`, `checkMembershipCapacity`,
  `tierAfterManagerGrant` (the promotion raises its own ceiling), `canCreateCompany`,

  `assertMembershipCapacity` → 409 `COMPANY_LIMIT_REACHED`, `limitMessageFor`

### Traps worth remembering
- React SSR puts `<!-- -->` between adjacent text expressions, so
  `toContain('0 of 1')` against raw HTML fails for the right reason the wrong way —

## Part 6 — single administrator: everything wiped, one login left

Request: delete every existing account, then hand the platform to exactly one
admin — `mozammelhaquexo@gmail.com` / `mozam8989##@@` — with no other route to
the Admin Panel.

- **`scripts/reset-single-admin.ts`** (new): prints per-table row counts first,
  then `TRUNCATE ... CASCADE` on every table EXCEPT `_prisma_migrations` and

  signup, 2026-10-03 17:22). Deleted as part of "all accounts". Everything else
  was seed/demo or test residue.
- **`scripts/verify-single-admin.mjs`** (new) — **24/24** live: login →
  SUPER_ADMIN; 7 admin APIs + `/admin` → 200; a fresh signup is USER and gets
  403 on all 7; `PATCH /api/admin/users/[id]` → **409 `SINGLE_ADMIN_ONLY`** even
  for the admin themselves; signed-out API → 401; wrong password → 401.
- **Three probe assertions were wrong, not the product**: `/admin` answers a
  non-admin with **200** on purpose — `NotAuthorized` (a server component) for a

  `<meta http-equiv="refresh" content="1;url=/login">`). The real invariant is
  **no admin-shell markup leaks** — asserted with a marker list
  (`Admin console toolbar`, `href="/admin/users"`, `Audit logs`, …): 0 leaks in
  every case. `app/(app)/admin/layout.tsx` is the guard and it works.
- `signup/verify` returns **201** (`created`), not 200.
